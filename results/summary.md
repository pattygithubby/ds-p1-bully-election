# Experiment results

Generated by `python -m experiments.run`. Every number below is in `in_memory.csv` and `udp.csv`.

## Scenarios

| Scenario | What happens |
|---|---|
| first election | All nodes start at the same time. |
| coordinator crash | The coordinator crashes; every node notices on its next timeout. |
| crash, one detector | The coordinator crashes; only the next-highest node notices (best case). |
| half crash | The highest half of the nodes crash at once. |
| coordinator returns | The crashed coordinator recovers and takes over again. |
| join lowest first | The nodes join one at a time, lowest id first (worst case). |
| join highest first | The nodes join one at a time, highest id first. |
| steady state | One check/timeout round with no failure: the cost of failure detection. |

## Correctness

- Assertion 1 (safety) was checked 59,197 times during the in-memory runs, after every state change of every node. It never failed.
- 228 of 228 runs ended with every live node agreeing on the highest live node (Assertion 2, and the expected leader).
